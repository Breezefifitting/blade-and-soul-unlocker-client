## 🧩 About

**Blade and Soul catalog Client** is a curated list of Blade and Soul open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD viewer, config switcher
- **Quality-of-Life Helpers** — inventory catalog, skin manager, overlay notes
- **Research Notes** — combat layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- Skill Timer Overlay — track cooldowns with a visual timer
- Target Info HUD — show target health and distance
- Combat Log Notes — record and review combat events
- Action Speed — adjust playback speed for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Costume Catalog — browse outfits, colors, and accessories
- Custom Skin Notes — organize character cosmetics
- Weapon Skin Viewer — improved weapon visibility

### 🏋️ Training Layout
- Training Mode Notes — segment study on any layout
- Stance Switch Control — manually switch stances mid-combat
- Combo Buffer Notes — chain complex maneuvers in the editor
